arXiv Research Assistant

A research assistant that answers machine learning and NLP questions using 2,821 recent arXiv paper abstracts. It finds the five most relevant papers for each question, then Claude writes an answer that cites them as [1] to [5] and says so when the papers do not cover the question.

I built the full pipeline: data collection from the arXiv API, cleaning, embeddings, a vector database, the prompt, a Streamlit web app, and a retrieval evaluation.

Code and README on GitHub
  1. CollectarXiv API2,821 papers from cs.CL and cs.LG, cleaned with pandas
  2. Embedsentence-transformersall-MiniLM-L6-v2, 384-dimension vectors
  3. StoreChromaDBLocal vector database with titles and IDs
  4. Retrieve + answerTop 5 → ClaudePrompt limits answers to the retrieved abstracts, with citations
  5. ServeStreamlitWeb app with expandable sources and arXiv links
Retrieval evaluation · 20 sampled papers
Test questionsHit rate @5MRR
Easy: use the paper's own technical terms100%1.00
Hard: short, everyday wording60%0.42

What I learned. My first evaluation scored a perfect 100%, which was a sign the test was too easy: the generated questions reused each abstract's vocabulary. I rewrote the test to use everyday phrasing, closer to how people actually ask, and the score dropped to 60%.

That gap points to the next improvements: hybrid keyword and vector search, a reranking step, and a larger evaluation set.
